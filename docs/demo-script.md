# 示範影片腳本（約 2 分鐘）

錄之前：`ollama ps` 要是空的或只有 `gpt-oss:20b`；`video_transfer` 不能在跑。
先把站台開好：`uv run python -m aoi_agent station`，瀏覽器開 `http://127.0.0.1:8110`，
語言切到中文。store 裡要有跑過的板（`/boards` 上「已定案」不是 0）。

每一幕：先說一句話，再做動作。旁白照這裡念就好。

| # | 秒 | 畫面 | 旁白 |
|---|---|---|---|
| 1 | 0–10 | 終端機：`uv run python -m aoi_agent board 20085294 --queue` | 「AOI 標了九個區域。視覺模型 2.5 毫秒判掉八個，剩一個它不敢判，交給人。」 |
| 2 | 10–25 | 佇列頁 `/` | 「這是等人看的清單。每一列有模型的判定、信心、P(誤判)，還有 agent 寫的說明——它只解釋，不決定。等最久的排最前。」 |
| 3 | 25–45 | 點進 `20085294#7` | 「範本、待測板、差異圖並排；右邊是這台機器的缺陷率和這一類的驗收標準。這頁**不顯示答案**，因為作業員的答案就是下一輪的訓練標籤。」 |
| 4 | 45–55 | 按 `0`（我不確定）→ `/deferred` | 「看不出來就按 0。它不會變成一個判定，區域換到另一個隊伍，等資深的人。」 |
| 5 | 55–65 | 登出 → `watcher` 登入 → 開同一區 | 「一般作業員打開它，按鈕不見。退回的區域只有資深能答——這是這個站唯一的權限。」 |
| 6 | 65–75 | `/boards` | 「板的索引：已定案、扣住、放行、等待中。分母在這裡，不在佇列。」 |
| 7 | 75–100 | `/ask` 問「M32 參數變更前後，open 的比例有沒有變？」 | 「主管的問題變成一份型別化的查詢計畫，先驗證再跑。三個查詢平行跑，圖從結果的形狀畫出來，最後模型寫一段話在數字旁邊。前後兩根柱、區間不重疊。」 |
| 8 | 100–110 | 同一頁問 M31 換燈 | 「對照組：換燈沒效果，兩根區間重疊。工具會說『沒差』，不是有事件就有影響。」 |
| 9 | 110–120 | 按 English | 「切語言：問題和規劃段留原文並標記，答案從同一批結果重寫，不是翻譯。」 |

收尾一句：「每個門檻都引得到一支跑得起來的腳本；每個數字都在 `docs/benchmarks.md`，新的在最後。」

錄完放哪：`docs/demo.mp4`（gitignore 外，記得 `git lfs` 或改放 YouTube 連結），
然後把 README 兩個版本的「Demo」區塊裡的佔位段換成連結。
