站台開好（`uv run python -m aoi_agent station`），瀏覽器 1280×800、深色、語言中文。
store 裡要有：一片剛跑完、有區域在待複判的 PCB（例如 `00041208`，區域 #8）；

**節奏規則**
- 切頁後停一秒再講；講完一幕再切，不要邊講邊切。
- 滑鼠只在「指」的時候動，其他時候拿開。
- 第 7 幕等模型的 20–30 秒不要沉默：講「規劃、驗證、平行」那三句剛好蓋過去。
- 不要示範第二題的現場等待——用已問過的頁面。
