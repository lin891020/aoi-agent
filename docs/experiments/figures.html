省下的人工（review removed）
假警報裡被模型直接撤掉、不用人看的比例。
漏率（escape rate）
真缺陷被當成假警報放走的比例，分母是真缺陷數。
理想欄 / 部署欄（oracle / deployed）
理想欄是在測試集上直接挑最好的門檻，只能拿來比模型；部署欄是門檻在別的資料上先選好，才是真的會用的數字。
種子（seed）
訓練用的隨機起點；換一個就是重跑一次整個流程。
batch
Ollama 一次送幾個 token 進 GPU 算；改變它會改變浮點數加法的順序。
